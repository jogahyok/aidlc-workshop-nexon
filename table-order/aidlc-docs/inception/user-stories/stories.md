# 사용자 스토리

## 스토리 구성: User Journey-Based
- **우선순위 체계**: P1 (필수) / P2 (중요) / P3 (선택)
- **수용 기준 형식**: Given/When/Then (5~8개 시나리오)
- **스토리 크기**: 기능 하나당 1개 스토리

---

## 고객 여정 (Customer Journey)

### US-01: 테이블 자동 로그인
**As a** 식당 고객  
**I want to** 테이블에 앉으면 별도 로그인 없이 바로 주문 화면을 볼 수 있다  
**So that** 대기 시간 없이 즉시 주문을 시작할 수 있다

**Priority**: P1  
**Persona**: 식당 고객

**Acceptance Criteria**:
1. Given 관리자가 태블릿에 매장/테이블 정보를 초기 설정했을 때, When 태블릿 브라우저를 열면, Then 자동으로 로그인되어 메뉴 화면이 표시된다
2. Given 자동 로그인이 성공했을 때, When 메뉴 화면이 로드되면, Then 해당 매장의 메뉴가 카테고리별로 표시된다
3. Given QR코드로 접속한 경우, When 모바일 브라우저에서 URL을 열면, Then 해당 테이블의 주문 화면이 표시된다
4. Given 저장된 로그인 정보가 유효하지 않을 때, When 자동 로그인을 시도하면, Then 에러 메시지가 표시되고 관리자에게 재설정을 요청하는 안내가 나온다
5. Given 페이지를 새로고침했을 때, When 화면이 다시 로드되면, Then 자동 로그인 상태가 유지된다

---

### US-02: 메뉴 조회 및 탐색
**As a** 식당 고객  
**I want to** 카테고리별로 메뉴를 탐색하고 상세 정보를 확인할 수 있다  
**So that** 원하는 메뉴를 쉽게 찾아 선택할 수 있다

**Priority**: P1  
**Persona**: 식당 고객

**Acceptance Criteria**:
1. Given 메뉴 화면에 접속했을 때, When 화면이 로드되면, Then 카테고리 목록과 첫 번째 카테고리의 메뉴가 카드 형태로 표시된다
2. Given 메뉴 목록이 표시될 때, When 각 메뉴 카드를 보면, Then 메뉴명, 가격, 설명, 이미지가 표시된다
3. Given 여러 카테고리가 있을 때, When 다른 카테고리를 선택하면, Then 해당 카테고리의 메뉴 목록으로 빠르게 전환된다
4. Given 터치 디바이스에서 사용할 때, When 메뉴 카드나 버튼을 터치하면, Then 최소 44x44px 크기의 터치 영역으로 쉽게 조작할 수 있다
5. Given 메뉴 이미지가 있을 때, When 메뉴 카드가 렌더링되면, Then S3에서 로드된 이미지가 적절한 크기로 표시된다

---

### US-03: 메뉴 옵션 선택
**As a** 식당 고객  
**I want to** 메뉴의 사이즈, 토핑, 맵기 등 옵션을 선택할 수 있다  
**So that** 내 취향에 맞게 커스터마이징된 메뉴를 주문할 수 있다

**Priority**: P1  
**Persona**: 식당 고객

**Acceptance Criteria**:
1. Given 옵션이 있는 메뉴를 선택했을 때, When 메뉴 상세/옵션 화면이 열리면, Then 해당 메뉴의 옵션 그룹(사이즈, 토핑 등)이 표시된다
2. Given 필수 옵션 그룹이 있을 때, When 필수 옵션을 선택하지 않고 장바구니에 추가하려 하면, Then 필수 옵션 선택을 요구하는 안내가 표시된다
3. Given 옵션을 선택할 때, When 추가 가격이 있는 옵션을 선택하면, Then 총 가격이 실시간으로 업데이트된다
4. Given 선택 옵션 그룹에 최대 선택 수가 있을 때, When 최대 수를 초과하여 선택하려 하면, Then 추가 선택이 제한되고 안내 메시지가 표시된다
5. Given 모든 필수 옵션을 선택했을 때, When 장바구니 추가 버튼을 누르면, Then 선택한 옵션 정보와 함께 장바구니에 추가된다

---

### US-04: 장바구니 관리
**As a** 식당 고객  
**I want to** 선택한 메뉴를 장바구니에 담고 수량을 조절할 수 있다  
**So that** 주문 전에 내용을 확인하고 수정할 수 있다

**Priority**: P1  
**Persona**: 식당 고객

**Acceptance Criteria**:
1. Given 메뉴를 장바구니에 추가했을 때, When 장바구니를 확인하면, Then 메뉴명, 선택 옵션, 수량, 금액이 표시된다
2. Given 장바구니에 항목이 있을 때, When 수량 증가/감소 버튼을 누르면, Then 수량과 총 금액이 실시간으로 업데이트된다
3. Given 장바구니에 항목이 있을 때, When 삭제 버튼을 누르면, Then 해당 항목이 제거되고 총 금액이 재계산된다
4. Given 장바구니에 항목을 담은 후, When 페이지를 새로고침하면, Then 장바구니 내용이 유지된다 (로컬 저장)
5. Given 장바구니에 여러 항목이 있을 때, When 장바구니 비우기를 실행하면, Then 모든 항목이 제거되고 총 금액이 0이 된다
6. Given 장바구니가 비어있을 때, When 장바구니를 확인하면, Then 비어있음을 안내하고 메뉴로 이동하는 버튼이 표시된다

---

### US-05: 주문 생성
**As a** 식당 고객  
**I want to** 장바구니의 메뉴를 주문으로 확정할 수 있다  
**So that** 매장에 주문이 전달되어 음식을 받을 수 있다

**Priority**: P1  
**Persona**: 식당 고객

**Acceptance Criteria**:
1. Given 장바구니에 항목이 있을 때, When 주문 확정 버튼을 누르면, Then 주문 내역(메뉴, 옵션, 수량, 총 금액)이 최종 확인 화면에 표시된다
2. Given 최종 확인 화면에서, When 주문을 확정하면, Then 서버에 주문이 전송되고 주문 번호가 표시된다
3. Given 주문이 성공했을 때, When 주문 번호가 표시된 후 5초가 지나면, Then 장바구니가 비워지고 메뉴 화면으로 자동 리다이렉트된다
4. Given 주문 전송 중 오류가 발생했을 때, When 서버 응답이 실패하면, Then 에러 메시지가 표시되고 장바구니 내용은 유지된다
5. Given 주문이 전송될 때, When 서버에 주문 데이터가 도착하면, Then 매장 ID, 테이블 ID, 메뉴 목록(옵션 포함), 총 금액, 세션 ID가 포함된다

---

### US-06: 주문 내역 조회
**As a** 식당 고객  
**I want to** 현재 식사 세션의 주문 내역과 상태를 확인할 수 있다  
**So that** 주문한 메뉴와 진행 상태를 파악할 수 있다

**Priority**: P1  
**Persona**: 식당 고객

**Acceptance Criteria**:
1. Given 주문 내역 화면에 접속했을 때, When 화면이 로드되면, Then 현재 테이블 세션의 주문만 시간 순으로 표시된다
2. Given 주문 내역이 표시될 때, When 각 주문을 확인하면, Then 주문 번호, 시각, 메뉴/옵션/수량, 금액, 상태(대기중/준비중/완료)가 표시된다
3. Given 이전 세션(매장 이용 완료 처리된)의 주문이 있을 때, When 주문 내역을 조회하면, Then 이전 세션의 주문은 표시되지 않는다
4. Given 관리자가 주문 상태를 변경했을 때, When 주문 내역 화면을 확인하면, Then 변경된 상태가 반영되어 표시된다
5. Given 여러 건의 주문이 있을 때, When 목록을 스크롤하면, Then 페이지네이션 또는 무한 스크롤로 모든 주문을 확인할 수 있다

## 관리자 여정 (Admin Journey)

### US-07: 매장 관리자 인증
**As a** 매장 관리자  
**I want to** 매장 식별자와 계정 정보로 로그인할 수 있다  
**So that** 내 매장의 관리 시스템에 안전하게 접근할 수 있다

**Priority**: P1  
**Persona**: 매장 관리자

**Acceptance Criteria**:
1. Given 관리자 로그인 페이지에서, When 매장 식별자, 사용자명, 비밀번호를 입력하고 로그인하면, Then JWT 토큰이 발급되고 관리 대시보드로 이동한다
2. Given 로그인에 성공했을 때, When 16시간이 경과하면, Then 자동으로 로그아웃되고 로그인 페이지로 이동한다
3. Given 로그인 상태에서, When 브라우저를 새로고침하면, Then 세션이 유지되어 재로그인 없이 사용할 수 있다
4. Given 잘못된 비밀번호로 반복 시도할 때, When 일정 횟수를 초과하면, Then 로그인 시도가 제한되고 안내 메시지가 표시된다
5. Given 유효하지 않은 매장 식별자를 입력했을 때, When 로그인을 시도하면, Then 적절한 에러 메시지가 표시된다

---

### US-08: 실시간 주문 모니터링
**As a** 매장 관리자  
**I want to** 들어오는 주문을 실시간으로 확인하고 상태를 관리할 수 있다  
**So that** 빠르게 주문을 처리하고 고객 대기 시간을 줄일 수 있다

**Priority**: P1  
**Persona**: 매장 관리자

**Acceptance Criteria**:
1. Given 관리 대시보드에 접속했을 때, When 화면이 로드되면, Then 테이블별 그리드 카드 레이아웃으로 현재 주문 현황이 표시된다
2. Given 고객이 새 주문을 생성했을 때, When SSE를 통해 주문이 수신되면, Then 2초 이내에 해당 테이블 카드에 새 주문이 표시되고 시각적으로 강조된다
3. Given 테이블 카드가 표시될 때, When 카드를 확인하면, Then 테이블 번호, 총 주문액, 최신 주문 미리보기가 표시된다
4. Given 테이블 카드를 클릭했을 때, When 상세 보기가 열리면, Then 해당 테이블의 전체 주문 메뉴 목록이 표시된다
5. Given 주문 상세를 확인할 때, When 상태 변경 버튼을 누르면, Then 주문 상태가 대기중→준비중→완료로 변경된다
6. Given 테이블별 필터링 기능이 있을 때, When 특정 테이블을 필터링하면, Then 해당 테이블의 주문만 표시된다

---

### US-09: 테이블 관리
**As a** 매장 관리자  
**I want to** 테이블 설정, 주문 삭제, 세션 종료를 관리할 수 있다  
**So that** 테이블 운영을 효율적으로 관리하고 새 고객을 맞을 준비를 할 수 있다

**Priority**: P1  
**Persona**: 매장 관리자

**Acceptance Criteria**:
1. Given 테이블 초기 설정 시, When 테이블 번호와 비밀번호를 입력하면, Then 테이블이 등록되고 태블릿 자동 로그인이 활성화된다
2. Given 특정 주문을 삭제해야 할 때, When 삭제 버튼을 누르고 확인 팝업에서 확인하면, Then 주문이 즉시 삭제되고 테이블 총 주문액이 재계산된다
3. Given 고객이 식사를 마쳤을 때, When 테이블 이용 완료 버튼을 누르고 확인하면, Then 현재 세션의 주문이 과거 이력으로 이동하고 테이블이 리셋된다
4. Given 테이블 세션이 종료된 후, When 새 고객이 주문을 시작하면, Then 이전 주문 내역 없이 새로운 세션으로 시작된다
5. Given 과거 내역을 확인하고 싶을 때, When 과거 내역 버튼을 누르면, Then 해당 테이블의 과거 주문 목록이 시간 역순으로 표시되고 날짜 필터링이 가능하다
6. Given 주문 삭제나 세션 종료 작업 후, When 작업이 완료되면, Then 성공/실패 피드백이 표시된다

---

### US-10: 메뉴 관리
**As a** 매장 관리자  
**I want to** 메뉴와 옵션을 등록, 수정, 삭제할 수 있다  
**So that** 매장의 메뉴를 최신 상태로 유지하고 고객에게 정확한 정보를 제공할 수 있다

**Priority**: P1  
**Persona**: 매장 관리자

**Acceptance Criteria**:
1. Given 메뉴 관리 화면에서, When 새 메뉴를 등록할 때, Then 메뉴명, 가격, 설명, 카테고리, 이미지(S3 업로드)를 입력하고 저장할 수 있다
2. Given 메뉴가 등록되어 있을 때, When 메뉴 정보를 수정하면, Then 변경 사항이 즉시 반영되어 고객 화면에 표시된다
3. Given 메뉴를 삭제할 때, When 삭제를 확인하면, Then 메뉴가 목록에서 제거된다
4. Given 메뉴에 옵션을 추가할 때, When 옵션 그룹(필수/선택)과 옵션 항목(이름, 추가 가격)을 설정하면, Then 고객 주문 시 해당 옵션이 표시된다
5. Given 메뉴 노출 순서를 변경할 때, When 드래그 또는 순서 조정 기능을 사용하면, Then 고객 화면에서 변경된 순서로 메뉴가 표시된다
6. Given 필수 필드가 비어있을 때, When 메뉴를 저장하려 하면, Then 검증 에러가 표시되고 저장이 차단된다
