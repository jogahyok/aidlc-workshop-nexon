# 컴포넌트 정의

## 아키텍처 개요
- **백엔드**: 도메인별 마이크로서비스 (FastAPI)
- **프론트엔드**: 모노레포 (공통 컴포넌트 공유, 고객용/관리자용 별도 빌드)
- **데이터 접근**: Raw SQL + 데이터 매퍼 패턴
- **서비스 내부 통신**: 직접 함수 호출
- **서비스 간 통신**: HTTP/REST
- **상태 관리**: React Context + useReducer

---

## 백엔드 마이크로서비스

### 1. Auth Service (인증 서비스)
- **책임**: 관리자 인증, 테이블 태블릿 인증, JWT 토큰 관리
- **도메인**: 관리자 계정, 테이블 세션 토큰
- **인터페이스**: REST API
- **데이터베이스**: 자체 스키마 (admins, table_credentials)

### 2. Store Service (매장 서비스)
- **책임**: 매장 정보 관리, 테이블 관리, 테이블 세션 라이프사이클
- **도메인**: 매장, 테이블, 테이블 세션
- **인터페이스**: REST API
- **데이터베이스**: 자체 스키마 (stores, tables, table_sessions)

### 3. Menu Service (메뉴 서비스)
- **책임**: 메뉴 CRUD, 카테고리 관리, 옵션 그룹/항목 관리, 이미지 업로드
- **도메인**: 카테고리, 메뉴 항목, 옵션 그룹, 옵션 항목
- **인터페이스**: REST API
- **데이터베이스**: 자체 스키마 (categories, menu_items, option_groups, option_items)

### 4. Order Service (주문 서비스)
- **책임**: 주문 생성, 주문 상태 관리, 주문 내역 조회, SSE 실시간 알림, 주문 삭제, 과거 이력 관리
- **도메인**: 주문, 주문 항목, 주문 항목 옵션, 주문 이력
- **인터페이스**: REST API + SSE 엔드포인트
- **데이터베이스**: 자체 스키마 (orders, order_items, order_item_options, order_history)

### 5. API Gateway (게이트웨이)
- **책임**: 요청 라우팅, 인증 토큰 검증, CORS 처리, Rate Limiting, 보안 헤더
- **도메인**: 없음 (인프라 컴포넌트)
- **인터페이스**: 외부 진입점

---

## 프론트엔드 (모노레포)

### 6. Customer App (고객용 앱)
- **책임**: 메뉴 조회, 옵션 선택, 장바구니 관리, 주문 생성, 주문 내역 조회
- **주요 화면**: 메뉴 목록, 메뉴 상세/옵션, 장바구니, 주문 확인, 주문 내역
- **상태 관리**: React Context + useReducer (장바구니, 인증 상태)

### 7. Admin App (관리자용 앱)
- **책임**: 로그인, 실시간 주문 모니터링, 테이블 관리, 메뉴 관리
- **주요 화면**: 로그인, 주문 대시보드, 테이블 관리, 메뉴 관리
- **상태 관리**: React Context + useReducer (인증, 주문 목록)

### 8. Shared UI Library (공통 컴포넌트)
- **책임**: 공통 UI 컴포넌트, 유틸리티, 타입 정의, API 클라이언트
- **포함 항목**: 버튼, 모달, 카드, 로딩 스피너, API 호출 유틸리티, 공통 타입

---

## 인프라 컴포넌트

### 9. Database (MySQL RDS)
- **책임**: 데이터 영속화
- **구성**: 서비스별 스키마 분리 (단일 RDS 인스턴스, 논리적 분리)

### 10. Object Storage (S3)
- **책임**: 메뉴 이미지 저장
- **접근**: Menu Service를 통한 Presigned URL 발급

### 11. Load Balancer (ALB)
- **책임**: 트래픽 분산, SSL 종료, 서비스 라우팅
